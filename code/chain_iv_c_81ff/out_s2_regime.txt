(R4) WHAT IS NOT SETTLED, AND HOW MANY INFORMATIVE POINTS THERE ARE
------------------------------------------------------------------------------

  NOT SETTLED: whether `c >= 40/49` holds for EVERY poset in the regime.  The
  regime is empty at every n this or any enumeration reaches (0 of 86 277 at
  n = 7), so the class cannot be swept; the evidence for it is two constructed
  families, which is 2 points and not a population.

  THE ONE READING THAT RUNS AGAINST IT, stated because it is the one a reader
  would otherwise find later: at a FIXED gap cap, `min c` falls as n grows —
  0.974 -> 0.869 -> 0.859 at eps = 0.10 for n = 5, 6, 7, and 0.989 -> 0.881 at
  eps = 0.06 for n = 6, 7.  That is TWO and THREE informative points respectively,
  it is confounded with population size (a min over more posets falls for free),
  and every value is still above both thresholds.  IT IS NOT EVIDENCE THAT c
  DROPS BELOW THE THRESHOLD IN THE REGIME, AND IT IS NOT EVIDENCE THAT IT DOES
  NOT.  Four points killed 2/(n+1); three points decide nothing here either.
