## The defect this instrument caught in itself

`s0` exists because it found one. The first `count_extensions` peeled any element whose
down-set was contained in the remainder — **true of every minimal element, not only maximal
ones**. It returned the **right answers** at every `n` (dead branches contribute `0`) while
walking all `2^n` subsets instead of the `2n`-element down-set lattice. A numbers-only check
at `n ≤ 7` could never have seen it; what saw it was the run not finishing at `n = 17`.

`s0` §C keeps it caught by **mutation**: it reconstructs the broken predicate, asserts the
answer is still numerically correct, and asserts the state count exceeds the lattice size by
`>100×`. Both assertions must hold, so the control cannot rot into a tautology.

The general point, and it is the one worth carrying: **a check that compares only numbers
cannot see a defect that changes only cost** — and a defect that changes only cost is still a
defect, because it decides which `n` you can reach, and every `n`-freeness question in this
corpus is decided by how far the sweep got.
