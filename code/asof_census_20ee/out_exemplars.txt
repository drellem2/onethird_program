5  WHAT THIS FILE CANNOT SAY, RESTATED WHERE IT IS READ
------------------------------------------------------------------------------

  * OVERTAKEN IS NOT STALE.  A pin is not a repair, and a reference
    may be to something the pin did not touch.  It says the record
    has not spoken since; it does not say what changed.
  * NOT OVERTAKEN IS NOT CURRENT.  212 pairs are not flagged, and
    that is a statement about the REPOSITORY.  An instrument goes
    stale when its CORPUS moves and no pin lands on it at all.
  * BLAME IS THE LAST TOUCH, NOT THE ORIGIN.  A reflow re-dates a
    sentence it did not change, so the OVERTAKEN count is a LOW
    WATER MARK.  N29 asserts that on the rule.
  * ZERO MENTIONS IS ZERO PAIRS.  1 work-list row(s) are named by
    no record in the tree -- code/summary_guard_audit_407f -- and this rule
    is blind to them BY CONSTRUCTION: a record that should name an
    instrument and never does cannot have a last word about it.
    N30 counts them, and the count is the one figure here that
    GROWS when the corpus gets worse.
  * THE ORDER INDEX ASSUMES A LINEAR HISTORY.  There are 0 merge
    commits at AS_OF, because the refinery REBASES -- so the
    comparison is exact HERE by a property of the repository and not
    by anything this file does.  Counted rather than assumed.
