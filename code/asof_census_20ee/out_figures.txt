1  THE UNIT IS A FIGURE, AND THAT IS THE WHOLE CHANGE
------------------------------------------------------------------------------

  pathlist.py grades a PRODUCER by what it reads and stops there:
  305 transcripts came back MIXED, meaning `reads a path list AND
  content`, with nothing said about WHICH of their figures is
  which.  A figure is an interpolated value on a printed line, so
  it is an expression in the producer's source, and `is this
  expression a function of the tracked path list` is a BACKWARD
  SLICE over that source.

      PATH-LIST-VALUED  the slice CLOSES and every root of it is a
                        tracked-path-list read, a literal, or a
                        non-repository input.  A PROOF: the figure
                        is re-derivable at any commit by
                        liveindex.py's method.
      CONTENT-VALUED    a content, history or blame read is in the
                        slice.  Also a proof, of the other thing.
      UNDECIDED         the slice does not close -- an unresolved
                        name, an unresolved call, or a parameter
                        with no visible caller.  CLAIMS NOTHING.
      CONSTANT          no repository input at all: a rule, a
                        heading, a number this file computed from
                        literals.  Not a figure about the corpus.

  ALMOST EVERY FAILURE OF THIS ANALYSIS LANDS IN UNDECIDED, AND
  THE EXCEPTION IS NAMED RATHER THAN GLOSSED.  An unresolved name,
  call or parameter cannot manufacture a PATH-LIST-VALUED verdict,
  so the class that is a claim of proof is only ever made SMALLER
  by a defect of that kind.  N35 plants the one shape that escapes
  it: an assignment is recorded in the scope it is WRITTEN in, so a
  global filled by `X.append(...)` INSIDE a function is invisible
  to a use at module level, which reads `X = []` and sees a
  literal.  A figure whose real slice runs through such a global
  can come back a PROOF.  EXHIBITED IN A PLANT, LATENT HERE:
  nothing below counts how many of the PATH-LIST-VALUED figures
  have that shape, and that is the next reader's measurement.

  A ROW THAT CANNOT BE LOCATED IS PRINTED AND IS NOT A PASS.  An
  anchor that silently matched nothing would agree with everything,

  COARSER.  liveindex.py's readers are REGEXES OVER A COMMITTED

  second is `subject scripts` again, already checked two sections
  earlier and re-derivable here.  That is what per-FIGURE buys over
  per-LINE, and it is the only thing this file claims to buy.

4  THE CHECK THAT NEEDS NO HUMAN -- A CROSS-INSTRUMENT INVARIANT
------------------------------------------------------------------------------

  pathlist.py grades 535 producers NO PATH-LIST READ.  By its own
  rule not one figure of any of them can be a function of the path
  list, because their closures never read one.  So this file's
  PATH-LIST-VALUED count over that class must be EXACTLY 0, and it
  is a number this file does not get to choose.

        520  NO PATH-LIST READ producers parsed
          0  figures graded PATH-LIST-VALUED among them

  NO VIOLATIONS.  That is a real constraint and not a tautology:
  the two instruments share the PATTERNS -- this file imports
  pathlist.PATHLIST and pathlist.OTHER rather than re-spelling
  them -- but NOT the unit, the traversal or the closure walk.
  pathlist.py matches its patterns against the whole flattened
  closure; this file matches them at individual CALL SITES that
  a slice from a print statement actually reaches.  A figure
  could be graded PATH-LIST-VALUED here out of a producer whose
  flattened body never matched PATHLIST at all -- that is
  precisely the disagreement this arm would catch.
