S2a  THE ARITY FLOOR, AND WHETHER `_classify`'S FORM CAN REACH IT
==========================================================================

  A k-valued function is a partition into at most k blocks; a pair is
  collapsed iff both words share a block.  The sum of C(n_i,2) is
  smallest at the most equal partition.  So no four-valued function on
  43 words can collapse fewer than:

  population: all four-valued FUNCTIONS on the 43 vocabulary words   @518a5e9
      ...PAIRS the best four-valued function still collapses      210
          ^ one unit is one pair of words;  label's own noun: `collapse`
      ...PAIRS the best four-valued function tells apart          693
          ^ one unit is one pair of words;  label's own noun: `apart`

  E1's CONTROL, BECAUSE THE FLOOR DEPENDS ON IT.  `_classify`'s four
  cells are (in EXEC only), (in SITE only), (in BOTH), (in NEITHER).
  If nothing can land in BOTH the function is three-valued in practice
  and the floor is 287, not 210.  So: a string that classifies BOTH.

      `_classify('rows executed')`               = BOTH
      `_classify('zzzz')`                        = NONE
      all four cells reachable                    YES -- the floor is 210

  AND THE FLOOR IS REACHED BY A FUNCTION OF EXACTLY THIS FORM, not by
  some other four-valued function.  Below: the 43 words dealt round-
  robin into the four cells, expressed as two membership sets, run
  through `two_test` -- two boolean tests, four symbols, same shape.

      cells: BOTH=11  EXECUTION=11  NONE=10  SITE=11
  population: the 43 vocabulary WORDS under a BALANCED four-cell assignment   @518a5e9

      the floor is ACHIEVED by `_classify`'s own form   YES
