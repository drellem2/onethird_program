(C) 'STABLE' vs 'STABLE UP TO THE RELABELLING THAT INDUCES IT'
==============================================================================
  setwise stabiliser   G(P)  = {sigma : sigma.AC(P) = AC(P)}
  gate's alternative   G'(P) = {sigma : AC(sigma P) = AC(P)}
  pointwise stabiliser G0(P) = {sigma : sigma.pi = pi for every pi in AC(P)}
  n=3: classes 5;  G(P) != G'(P) on 0 of them;  pointwise stabiliser nontrivial on 0
  n=4: classes 16;  G(P) != G'(P) on 0 of them;  pointwise stabiliser nontrivial on 0
  n=5: classes 63;  G(P) != G'(P) on 0 of them;  pointwise stabiliser nontrivial on 0
  So the two readings coincide (the action on AC(P) is by relabelling, and
  AC(sigma P) = sigma.AC(P) identically), while the POINTWISE stabiliser is
  trivial for n >= 2 -- 'stable' can only mean setwise, and the gate document
  states the setwise version and its equivalent form explicitly.
