## Two defects of this instrument, found by its own runs and kept

**1. A sweep rule that cannot tell a set of headings from a whole row manufactures the finding it is
looking for.** The first version reported `"FIGURE ORDER" in bad` in `audit_ec07.py` as the
construct. It is not: `bad` is `{heading(name, d) for ok, d in rows if not ok}` — a set of
**headings**, so the membership test is the *remedy*, spelled as a set lookup instead of as
`endswith`. Fixed by excluding comparators bound to a heading function's output; **and the fix was
short too**, reporting `"CENSUS ROSTER" not in moved` at `repair_7e39.py:692` as a seventh
occurrence live at `979df72`, where `moved` is `row_vocabulary(probe)` — a *vocabulary*. A rule that
widens a population by one and a vocabulary that narrows one by one are the same mistake, and this
audit made the first while measuring the second.

**2. The site's own length is one of the live figures.** `cell` is `len(state_row(...))`, so *any*
mutation that changes the STATE.md row's byte count moves a figure at all three sites. The first
version of the `K11` construction inserted one space and got exit 1 with **six FIGURE rows
refuted** — a K01 wearing K11's name, which is exactly the confusion this section exists to
prevent. The shift now **moves** a space rather than adding one: one cell gains the padding another
loses, length identical, figure-token multiset identical. `k_layout` reaches the same constraint
from the other side by shifting a *header* line, whose length is not a figure.

Both are in `PREDICTIONS.md`'s misses and in the transcript rather than smoothed away.
