A4b  section 8 C3, 'the smallest poset with AC(P) != Pi[n]' -- BROKEN
==============================================================================

  mg-7d75 section 8 C3 and T1e both say:
      "The smallest poset with AC(P) != Pi[n] is {a<c, b<d}, where the
       partition ad|bc has a 2-cycle in its quotient."
  and give the reason:
      "a cycle needs two blocks B, C with b1 < c1 and c2 < b2, which no
       poset on <= 2 elements admits."

  n = 1 :   1 labelled posets,   0 of them have AC(P) != Pi[n]
  n = 2 :   3 labelled posets,   0 of them have AC(P) != Pi[n]
  n = 3 :  19 labelled posets,   6 of them have AC(P) != Pi[n]
  n = 4 : 219 labelled posets, 174 of them have AC(P) != Pi[n]

  The smallest n with a witness is n = 3, not 4.
  Witnesses at n = 3 (all 6 of them, one isomorphism class -- the
  3-ELEMENT CHAIN, in its 6 labellings):
    P = [(0, 1), (0, 2), (1, 2)]     missing from AC(P): [[[0, 2], [1]]]
    P = [(0, 1), (0, 2), (2, 1)]     missing from AC(P): [[[0, 1], [2]]]
    P = [(0, 1), (2, 0), (2, 1)]     missing from AC(P): [[[0], [1, 2]]]
    P = [(0, 2), (1, 0), (1, 2)]     missing from AC(P): [[[0], [1, 2]]]
    P = [(1, 0), (1, 2), (2, 0)]     missing from AC(P): [[[0, 1], [2]]]
    P = [(1, 0), (2, 0), (2, 1)]     missing from AC(P): [[[0, 2], [1]]]

  The stated reason is sound as far as it goes and rules out n <= 2 --
  the two blocks need |B| >= 2 and |C| >= 1, so at least 3 elements --
  but the document then jumps to a 4-element example.  The 3-chain
  a < b < c with the partition {a,c} | {b} is a cycle: a < b goes one
  way and b < c goes the other.  {a<c, b<d} IS a witness; it is not
  the smallest one, and T1e's own row '13 of 19 at n = 3' records 6
  labelled witnesses at n = 3 two paragraphs above the claim.
