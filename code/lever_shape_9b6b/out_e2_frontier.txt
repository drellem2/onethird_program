VERDICT
    THE FRONTIER IS REAL AND IT IS UNCONSUMABLE, WHICH ARE NOT THE SAME SENTENCE.

    Everything G says is said about a class with delta >= 1/3.  Row 8 consumes G at
    delta < 1/3.  The two do not overlap, and the gap between them is not a matter of
    reaching a larger n: the class is empty at every n IF THE CONJECTURE HOLDS THERE,
    so a census can never populate it and can never fail to.  The measurable half of
    the frontier and the consumable half are disjoint by construction.

    WHAT THIS ARM DOES NOT SHOW.  It does not show a density-to-balance bound is FALSE
    -- e1 m3 shows the strict reading is, on the unrestricted class, and nothing here
    touches the flat one, which is true if and only if the conjecture is.  And every
    number here is kind FP at n <= 8: the staircase above 1/3 is unconditional
    information, but it is information about 20 000 posets, not about all of them.
