m2  WHAT EACH `D` DELIVERS, IN ORDERS OF THE CONJECTURE
    A frozen poset obeying `d <= D` and primitive would need 2/n <= D.  So (1_D)
    forbids one at every n with 2/n > D, and a minimal counterexample is primitive --
    the ceiling hands you the conjecture on an initial segment.  Census frontier: 14.

m3  WHAT THE CEILING EXEMPTS -- the same question from the other side
    `{d <= D}` is the class (1_D) lets off.  If it is empty, the ceiling is not a
    weakening of the conjecture at that n; it is the conjecture at that n.

      the sparsest non-chain has d = 1/C(n,2) = 2/(n(n-1))
      first n at which ANY non-chain poset is exempt at D_needed:   n = 11

    m3.a    ok      so at every n <= 10 the row-8 ceiling exempts NOT ONE non-chain poset -- it is the conjecture verbatim there, with no restriction at all
    m3.b    ok      and it exempts no primitive poset below n = 99, which is mg-0b96 d2's crossing arrived at from the exemption side

    THE DIRECTION IS THE POINT.  A ceiling closer to what the data shows is a STRONGER
    statement, not a more plausible one: it exempts less, so it asserts more.  The dial
    has no setting at which it stops being the conjecture and starts being a lemma --
    mg-0b96 §2's sentence -- and this arm adds the quantitative half: the settings get
    monotonically more expensive in exactly the direction the evidence points.

VERDICT
    NO SETTING OF THE DIAL IS BOTH PROVABLE AND WORTH ANYTHING, and the reason is not
    that the gap is large.  It is that value and price are THE SAME QUANTITY here:
    what a ceiling delivers is measured in orders of the conjecture, so a ceiling that
    delivers more IS a stronger statement.  mg-0b96 read that off one point; the
    family says it at every point, and says it hardest at the end the data points to.

    WHAT THIS ARM DOES NOT SHOW.  Nothing here shows any (1_D) is FALSE -- every one of
    them is true if the conjecture is.  And m1's and m4(b)'s F23 values above n = 9 are
    an extrapolation of an FP closed form; m4(a) is the same finding without it, and
    it is the one to quote.
