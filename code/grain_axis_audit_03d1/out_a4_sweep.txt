A4d  DOES THE FIX CONVERGE?  RUN IT TWICE AND DIFF -- THEN RESTORE
==========================================================================

  The parent's claim is that with the `mv`, the previous run's bytes
  survive the probe, so TWO CONSECUTIVE RUNS CONVERGE.  That is a claim
  about running it twice and is checked by running it twice.

  asserting cleanliness afterwards and going red if the restore fails.

  ticket's evidence regenerated; it does not forbid running it.
