A1b  AND THE LIMIT IS THE ARITY, NOT THE VOCABULARY
==========================================================================

  `_classify` is four lines long and its whole body is:

      e = bool(EXEC_WORDS.search(text));  s = bool(SITE_WORDS.search(text))
      BOTH if e and s;  EXECUTION if e;  SITE if s;  else NONE

  TWO independent boolean tests, so the function's image has at most
  four members and it partitions every possible label into at most four
  cells.  A partition into four cells can express exactly ONE binary
  distinction plus the two degenerate cells (`BOTH`, `NONE`).

  population: probe STRINGS chosen to reach every arm of the function
      distinct output WORDS `_classify` can return              4
      ^ one unit of that number is one output symbol
      ...boolean CHECKS the body performs                       2
      ^ one unit of that number is one regex membership test

  THIS IS THE FINDING.  The gap is not that `rows` is missing from some
  list -- `rows` is PRESENT, and that is the problem.  No addition to
  either word list can make `rows` and `sites` different, because the
  function has nowhere to put the difference.  A fix that adds a third
  vocabulary buys exactly one more axis and is the same shape of repair
  that produced this defect: one defect's width.

A1f  AND ONE AXIS IT REPORTS THAT IS NOT THERE
==========================================================================

  The blind spot has a mirror, and it is the prediction I most expected
  to be refuted: a pair of words at the SAME grain, split across the two
  vocabularies, so the classifier asserts a distinction the words do not
  carry.  ADJUDICATED BY HAND, with the reasoning printed so a reader
  can reject any row -- there is no mechanical test for `same grain`,
  and pretending there is would be this arc's own defect.

      `steps     `=SITE      vs `iterations  `=EXECUTION  same grain: yes  *** FALSE DISTINCTION
          a loop's steps ARE its iterations; `6 steps` and `6 iterations` of the same loop are one number
      `commands  `=SITE      vs `invocations `=EXECUTION  same grain: yes  *** FALSE DISTINCTION
          `3 commands issued` and `3 invocations` count the same events
      `runners   `=SITE      vs `runs        `=EXECUTION  same grain: no   
          a runner is a FILE and a run is an EVENT -- correctly split
      `scripts   `=SITE      vs `executions  `=EXECUTION  same grain: no   
          a script is a file; an execution is an event -- correctly split
      `checks    `=SITE      vs `iterations  `=EXECUTION  same grain: no   
          a check is written once and may iterate -- correctly split

  population: the 5 candidate WORD pairs adjudicated above
      ...PAIRS asserting a distinction not in the words         2
      ^ one unit of that number is one adjudicated word pair

  So the instrument is not merely coarse in one direction.  It collapses
  623 of the 903 pairs its own vocabulary can form AND splits at least 2
  pairs that are one grain.  Both errors are invisible to a check that
  only asks `does the label carry a grain word`.
