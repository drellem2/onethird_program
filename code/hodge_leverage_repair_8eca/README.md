## The two questions this is organised around

They are mg-8aae's, and its closing note says both findings are the same pair in different
clothes:

1. **Is the measured property invariant under the guarded failure?** A multiset is invariant
   under exchange; `x == x` is invariant under everything. So neither is fixed by checking more
   things — both are fixed by changing *what is measured*. R1 and R2 each show the new property
   **moving** under the exact failure the old one sat still for.
2. **Is the demonstration at the right target?** *Demonstrating a check fires via a test hook
   proves the hook works, not the check.* So R2's headline direction (**D2**) sets no
   environment variable: it edits the real file by hand, the way G-2 was actually made, and reads
   the transcript. **D4** then reinstates the two removed lines and shows the same artifact going
   uncaught again — without that control, "the check fires" and "the instrument fires" are the
   same sentence.
