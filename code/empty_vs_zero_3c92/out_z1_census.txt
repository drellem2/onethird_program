3.  COMPLIANCE -- THE RULE THE ESTATE ALREADY FOLLOWS
-----------------------------------------------------
    The carry-forward asks for a fallback a reader cannot mistake
    for a computed answer.  That is decidable: `None` and a string
    are not numbers.  TWO DISJOINT SPELLINGS ANSWER IT SEPARATELY.

    spelling                            keeps  loses  keeps %
    f(X) if X else <fallback>             734     93    88.8%
    max/min/next(..., default=...)        101     16    86.3%

    of the 734 preserving ternaries: 184 use `None`, 550 a string
    of the 101 preserving defaults:  89 use `None`, 12 a string

    THE TWO NUMBERS AGREE TO ONE PART IN FORTY OVER SPELLINGS THAT
    SHARE NO SYNTAX AND NO POPULATION, WHICH IS THE FINDING.  The
    rule mg-9b6b proposes is not a reform: it is a DESCRIPTION of
    what this estate already does about nine times in ten, arrived
    at without the rule ever being written down.  A proposal that
    is already practice is worth proposing for one reason only --
    to make the one-in-ten visible -- and that is sections 5 to 7.

    ⚠️  THE 550 STRING FALLBACKS ARE COUNTED AND ARE NOT A CLAIM OF
    INTENT.  Most are display defaults (`" %s" % x if x else ""`)
    that satisfy the criterion incidentally.  The criterion is
    about what a READER can recover, not about what an author
    meant, and it is stated that way everywhere in this directory.
    The `default=` row carries no such doubt: 89 of its 101 are
    `None`, on the same call, by the same author, in the same line.
