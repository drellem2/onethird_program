==============================================================================
Setting, taken from the audited documents and not re-derived here:
  * V = the span of L(P), one basis vector per linear extension;
  * E = diag(sgn w), the orientation twist (sgn = inversion parity of the
    word), so E is diagonal with entries +-1 and E.E = I;
  * Delta_AT = D - A, the graph Laplacian of the adjacent-transposition
    graph on L(P);   and the identity  Delta_AT = E . L^rel_top . E.
Write  ONE = sum_w e_w  (Daniel's plain sum) and  SGN = sum_w sgn(w) e_w.

-- the worked example P = {a<b, c<d}, every sign written out
   abcd   inversions 0   sgn = +1
   acbd   inversions 1   sgn = -1
   acdb   inversions 2   sgn = +1
   cabd   inversions 2   sgn = +1
   cadb   inversions 3   sgn = -1
   cdab   inversions 4   sgn = +1
   sign-imbalance  sum_w sgn(w)  =  +1 -1 +1 +1 -1 +1  =  +2

-- the one-line calculation
   E . ONE = [1, -1, 1, 1, -1, 1] = SGN : True
   E . SGN = [1, 1, 1, 1, 1, 1] = ONE : True
