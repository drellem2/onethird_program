    HYPOTHESIS CHECK.  Brown section 4.3 asks for a finite
    DISTRIBUTIVE lattice L.  J(P) is one (column 3).  By Birkhoff's
    theorem every finite distributive lattice is J(P) for a unique
    finite poset P, so section 4.3's class and ours are the SAME
    class -- the citation does not require anything we lack, and it
    does not cover a strictly smaller class either.
