[N3] 'NO DIFFERENTIAL POSET IS FINITE' -- the reason mg-41aa gives is
  definitional (locally finite, infinitely many ranks).  A stronger one:
  on a FINITE poset U and D are finite matrices, so tr(DU) = tr(UD) and
  tr(DU - UD) = 0, while tr(r.I) = r.|P| > 0.  No finite non-empty poset
  is r-differential for any r >= 1, whatever else it satisfies.
  The trace argument is a PROOF, not a measurement: with U the cover
  matrix and D = U^T, tr(DU) = tr(U^T U) = tr(U U^T) = tr(UD) for every
  finite poset whatsoever.  Running it over examples would be a
  restatement (the defect mg-3b51 flagged in this repo as R1d), so it
  is booked here as an ARGUMENT and not as evidence.

  built as a full matrix on every poset to n <= 6, counting how many
