(iii) IS THE COLUMN'S RENDERING INJECTIVE ON THE SETS THAT OCCUR?
--------------------------------------------------------------------------
   The column prints dimensions alone.  That is a FUNCTION of the vertex
   set, not the set.  It reports the set faithfully exactly when it is
   injective.  T1b2 checks this on the 36 SAME-LEVEL (parameter-pair,
   level) cells.  Checked here over EVERY unordered pair of the 24
   measured cells, across levels as well as across parameters.

   pairs compared: 276, population: every unordered pair of the 24 cells
   pairs where the RENDERING agrees and the SET does not: 0
   of which same-level pairs (the target's own population): 36
   same-level pairs where the COUNT agrees and the SET does not: 10 of 36

   WHY THE RENDERING IS INJECTIVE HERE, and it is a SIDE CONDITION and
   not a property of the rendering: the labels p carried by the live
   vertices are an unbroken run from 0 at every one of the 24 cells, so
   the dimension list determines the labels.  Measured:
     cells whose labels are NOT an unbroken run from 0: 0 of 24

--------------------------------------------------------------------------
(iv) TWO GENUINELY DIFFERENT VERTEX SETS, CONSTRUCTED
--------------------------------------------------------------------------
   A = [0:1,1:1]   --- two irreducibles, labelled p = 0 and p = 1
   B = [0:1,2:1]   --- two irreducibles, labelled p = 0 and p = 2

   These are DIFFERENT SETS: B's second vertex is L(n,2) and A's is
   L(n,1), which are different modules of the same dimension.  They are
   the pair a set column must separate and a count column cannot.

   count of A            : 2
   count of B            : 2   -> a COUNT column shows them EQUAL
   column rendering of A : [1,1]
   column rendering of B : [1,1]   -> the REPAIRED COLUMN ALSO SHOWS THEM
                                    EQUAL.
   full labelled form  A : [0:1,1:1]
   full labelled form  B : [0:1,2:1]   -> only this separates them

   SO THE COLUMN DOES NOT SEPARATE ARBITRARY VERTEX SETS.  What it
   separates is the vertex sets that satisfy the side condition in
   (iii).  Whether that is enough turns entirely on whether the side
   condition is GATED --- which is (v).  A rendering with an unchecked
   side condition is a count in disguise; a rendering with a checked
   one is not.

(vii) NO DIGEST STANDS IN FOR THE SET
--------------------------------------------------------------------------

   and not over a rendering of it.
   t1_tl.py       digest calls: 0
   t5_labels.py   digest calls: 4
