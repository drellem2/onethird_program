       AND THE MULTI-FIGURE ROWS DO NOT CLOSE THE LOOP, WHICH IS AN ACCIDENT
       OF FORMATTING AND NOT A SECOND DEFENCE.  P3 joins several missing
       figures with commas, and mg-7522's number rule reads a comma as a
       thousands separator, so `186,157,156` comes back as one figure:
           161, 186157156
       Nothing chose that.  Change the separator and the loop closes for
       every row, so the exclusion above is the defence and this is not.

      an UNCLOSED fence swallows the rest: [2, 3, 4]              ok

      a malformed README makes this arm quieter and never louder.  §5.3.

P5  WHAT THIS ARM CANNOT SEE
==============================================================================

  1  A QUOTATION IS NOT GRADED.  9 unbacked figure(s) sit inside a fence
     and are listed in P3 rather than counted against the verdict.  §2's
     ALL-CAPS derivation table is the big one: the frequency counts that
     chose the token set were produced by a run nobody kept, so THE ONLY
     JUSTIFICATION FOR THE INSTRUMENT IS ITSELF IN THE CLASS THIS DIRECTORY
     COUNTS.  Making it backed means re-taking that census and keeping it;
     that is remainder and it is filed, not absorbed here.

  2  A FIGURE THAT IS RIGHT IN THE SET AND WRONG IN ITS ROLE IS INVISIBLE,
     AND THE FOURTH DEFECT IN THIS DIRECTORY WAS ONE.  The rule is set
     MEMBERSHIP: a number printed ANYWHERE in a transcript of this directory
     backs the same number written ANYWHERE in its prose.  §4 said

         * **Killed at the limit.** 17 of 187 suites hit the 900 s cap. A proce

     where the record says 22 timed out, and THIS ARM DOES NOT FIRE ON IT:
         figures 17, 187, 900, none of them missing -> BACKED

     The 17 is BACKED, by 6 line(s) across this directory's transcripts, and
     0 of them carries the 900 s cap beside it -- so not one is the sentence
     §4 states.  The first, printed rather than paraphrased:
         out_owners_937c.txt:241  width  3-12 -> 17 hit(s)

     It was found by reading the record, not by this check.  Role needs a
     per-figure anchor, an anchor is a hand-typed quotation of the prose,
     and it rots silently the moment anybody rewords the sentence -- which is
     why this arm is a membership test and says so instead of pretending.

  3  AN UNCLOSED FENCE MAKES THIS ARM QUIETER, NEVER LOUDER.  P4d measures
     it.  Nothing here validates the README's markdown.

  4  THE `.py` DOCSTRINGS ARE OUTSIDE THE POPULATION, BY CHOICE AND NOT BY
     OVERSIGHT.  A docstring is read beside the code it describes, so a
     figure in one is usually backed by the CODE (`truncated at column 78`
     beside `text[:78]`), and a rule demanding a transcript for it would
     report the code as unbacked by itself.  The README is read INSTEAD of
     the record, so its figures can only be backed by a transcript.  The
     cost is real: a stale figure in a docstring is invisible here.
