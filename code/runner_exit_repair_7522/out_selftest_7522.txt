S9  THE SHELL ITSELF -- the rule in `guarded` is MEASURED, not cited
==============================================================================

  `lib7522.guarded` refuses to call `VAR=$(...)` a guard.  That is a
  claim about POSIX errexit, and mg-c2b3's own rule said the opposite.
  Both senses are run on `/bin/sh` on this machine:

  ok   assignment of a failing command aborts (exit)                  
  ok   assignment of a failing command aborts (later step ran)        
  ok   assignment of a failing PIPELINE does not (exit)               
  ok   assignment of a failing PIPELINE does not (later step ran)     

  So a pipeline inside an assignment is a place where a status is
  consumed and thrown away at the same time, and treating the
  assignment as a guard would have removed three real sites from the
  population.  The rule is measured here and applied in S1.
