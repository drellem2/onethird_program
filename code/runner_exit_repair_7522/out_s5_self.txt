S5d  D4 -- DOES THIS TREE USE A STRENGTH MARKER INSTEAD OF A CHECK?
==============================================================================

  A marker written INSIDE quotes, backticks or emphasis is a MENTION --
  the arc's way of naming a form of words it is discussing.  Written
  BARE, applied to a figure, it is a USE.  That distinction is the same
  one as `a comment quoting | tee is not a pipeline`, one level up, and
  the first draft of this check did not make it: it counted its own
  detecting regex as a violation, which is the arc's recurring defect
  in the instrument built to find it.  Recorded in OUTCOMES.md.

      MENTIONs in this tree                       18
      USEs in this tree                            0

  Every figure this tree prints is printed next to the predicate
  that produced it, in the same run -- which is the thing a
  strength marker is usually standing in for.

S5f  BRANCHES THAT HONESTLY CANNOT EXHIBIT THESE DEFECTS, WITH REASONS
==============================================================================

   1. D1 in `ls_sh()` -- the signature has no name parameter, so no
      name filter can be applied inside the primitive.  Checked in S5b.
   2. D2 in `s5_self.py` -- this file reads only the current world; it
      asks what THIS TREE says right now, and a pinned answer to that
      question would be about a tree that no longer exists.  0 pins.
   3. D3 in the Python -- list argv, no shell, no pipeline.  S5e.
   4. D3 in `selftest7522.py`'s fixtures -- they are STRINGS parsed by
      the rules, never executed, so no status exists to discard.
   5. D4 in the figures -- every one is recomputed in the run that
      prints it, so there is nothing for a strength marker to stand in
      for.  S5d checks that no marker is USED as well; MENTIONs are
      counted and allowed, because this tree's whole subject is those
      words and a rule that banned naming them would ban the finding.

  WHAT IS NOT CHECKED HERE, stated rather than omitted:

     transcripts.  A probe cannot check a sentence it does not know
     about; S3e does that job for mg-c2b3's artifacts and the same
     job for this tree's is done by a reader with both files open.
