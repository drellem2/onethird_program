§1  THE SCRUBBER — TWO WORLDS IT MUST EAT, THREE IT MUST NOT
--------------------------------------------------------------------------------------------
  `scrub_seconds` is the only normalisation v2 applies.  Widen it and v2's
  agreement is produced by the scrubber; narrow it and v2 is red on every host.

  N1   ok        a decimal second is eaten — the one field two runs of a fixed tree differ in
  N2   ok        every decimal second on a line, including the spaced spelling
  N3   ok        AN INTEGER IS NOT A SECOND — the count that opened mg-f771 must survive  <- MUST NOT FIRE
  N4   ok        `s` must be a whole token — `10.5seconds` is not a timing field  <- MUST NOT FIRE
  N5   ok        STATE.md's byte count is repo state and must not be scrubbed away  <- MUST NOT FIRE

  IT IS NOT INDEPENDENT IN SHAPE FROM lib_f771's N2 AND THAT IS NOT CLAIMED.
  There is one obvious regex for `a decimal followed by s`; both files hold it.
  What a separate file buys is that widening N2 cannot widen this arm's agreement
  test as a side effect.  It buys nothing else.
