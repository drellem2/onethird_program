p3.4  WOULD A FROZEN POSET EVEN HELP?  -- the bound, evaluated hypothetically
========================================================================================
  A frozen poset has every pair outside [1/3,2/3], hence mu < 1/3, hence
  alpha <= 1/(2(1-mu)) < 3/4.  Since the bar is a constant >= 2 (mg-409a section 2), the
  shortfall goes from a factor of 2 to a factor of 8/3.  Both are shortfalls.  The
  arithmetic below is unconditional -- it needs no poset to exist.
      mu =    1/3   ceiling 1/(2(1-mu)) = 0.750000000   bar/ceiling >= 2.6667
      mu =   3/10   ceiling 1/(2(1-mu)) = 0.714285714   bar/ceiling >= 2.8000
      mu =    1/4   ceiling 1/(2(1-mu)) = 0.666666667   bar/ceiling >= 3.0000
      mu =    1/5   ceiling 1/(2(1-mu)) = 0.625000000   bar/ceiling >= 3.2000
      mu =      0   ceiling 1/(2(1-mu)) = 0.500000000   bar/ceiling >= 4.0000
  PASS  at mu = 1/3 the ceiling is exactly 3/4   pm-onethird's number confirmed
  PASS  for every mu < 1/3 the ceiling is STILL below the bar of 2   the strengthening does not change the verdict, only the margin
