A5.1  the ELEMENTARY step: a union of two chains has width <= 2.
      (An antichain meets each chain at most once, so it has at most 2 elements.)
  OK   union of two chains has width <= 2: 0 / 508
       population: every bipartition of {0..n-1} into two increasing chains, n=2..8 (sum of 2^n = 508 posets)
       grain:      per-(n, bipartition), width computed by brute-force largest antichain

A5.2  the CITATION AS USED: over every poset of width <= 2, is delta >= 1/3?
      delta(P) = max over incomparable pairs {x,y} of min(pr(x<y), pr(y<x)).
      A CHAIN HAS NO INCOMPARABLE PAIR and therefore NO delta -- that is the rider
      item (e) needs and does not carry. Chains are reported separately below, not
      silently dropped.
  OK   width <= 2 and has an incomparable pair => delta >= 1/3: 0 / 3210
       population: all LABELLED posets on n=2..7 with e=identity a linear extension, filtered to width <= 2 and at least one incomparable pair: 3210 posets (out of 101658 total, of which 3216 have width <= 2)
       grain:      per-poset, exact Fraction comparison against 1/3
       tightest cell: delta = 1/3 at P1 n=3
       and the 6 width-<=2 posets with NO incomparable pair (the chains)
       have delta UNDEFINED -- delta() returns None for them, and they are
       excluded from the population above rather than counted as passing:
  OK   chains have delta undefined: 0 / 6
       population: the 6 width-<=2 posets on n=2..7 with no incomparable pair
       grain:      per-poset, delta() is None

  OK   width >= 3 => delta >= 1/3 (conjecture, n<=7): 0 / 98442

A5.4  the WHOLE of item (e), assembled: if both sides of the interface are chains,
