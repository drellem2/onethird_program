  Common: Step 5 needs Delta_1(A_k, A_k^c) = Phi_P(A_k) <= eps_leak, and s1's (D2)
  gives Phi_P(A_k) <= 1 - rho(A_k) <= 2 Phi_P(A_k).  So a bound on 1 - rho is a
  bound on Phi with no further loss, and vice versa up to a factor 2.

   chain   what it bounds                 eps_dem            n >= (mg-200d)
   -----   ---------------------------    ---------------    --------------
   (I)     Phi <= sqrt(2 eps_spec)        eps_leak^2 / 2     4/eps_leak^2 - 1
   (II)    Phi <= C_3 eps_spec            eps_leak / C_3     2 C_3/eps_leak - 1

  (III) at C_3 = 1 IS (I).  So the ticket's relation is chain (I) with a factor
  C_3 inserted at the one place chain (I) does not have one -- which is correct

  (II) is NOT (III) with C_3 moved.  The gap-form repair supplies the prefix

(B3) THE LITERAL READING -- Op-Form 4.3 calls it 'too weak to use'.  It is not.
------------------------------------------------------------------------------

  As worded: rho(A_k) >= c * lambda_std for a constant fraction c.  With
  lambda_std >= 1 - eps_spec this gives

      1 - rho  <=  1 - c(1 - eps_spec)  =  (1-c) + c*eps_spec

  Op-Form 4.3 reads the (1-c) term as a CONSTANT FLOOR and concludes the form is
  too weak to use.  The arithmetic is right.  The conclusion does not follow,
  because the consumer does not need a vanishing quantity -- it needs
  Phi <= eps_leak for an ABSOLUTE CONSTANT eps_leak, and Op-Form's own SS3.2
  is what establishes that eps_leak is an absolute constant.  A constant floor
  below a constant ceiling is usable.

  Solving 1 - c(1-eps_spec) <= eps_leak for eps_spec:

      eps_dem  =  1 - (1 - eps_leak)/c ,   usable for every  c > 1 - eps_leak
