B4(a) — does 'L4 fires' imply the Step-6 contradiction?
==============================================================================

mg-345e §3, arm B, point 1, verbatim:
   "L4 fired from a thin prefix reached without L1b contradicts `delta(P) < 1/3`
    outright - the frozen class is empty, and every statement about minimal
    counterexamples is vacuously true, `eps_spec` included."

L4-AS-STATED is a three-way disjunction. Branch by branch:

  (i)   P contains a 1/3-balanced pair
      contradiction follows : YES
      authority             : definition of delta(P): a 1/3-balanced pair IS delta(P) >= 1/3
      cited by mg-345e      : yes — mg-345e §5.1 row (i)

  (ii)  remove/modify <= F(eps)n interface elements -> P[A] (+) P[B]
      contradiction follows : NO
      authority             : mg-3af9 (audited mg-c8c6): unconsumable by Step 6's stated transfer for EVERY strictly positive F, sub-linear included
      cited by mg-345e      : yes — mg-345e §5.1 row (ii), cited verbatim with the 'strictly positive' quantifier

  (iii) AS STATED: a balanced pair remains balanced up to error F(eps)
      contradiction follows : NO
      authority             : Op-Form Claim 3.2 = ledger claim 8, labelled PROVEN: branch (iii) as literally stated cannot produce the Step 6 contradiction for any F > 0, under either reading
      cited by mg-345e      : yes — mg-345e reads the same ledger in §2 and §4

  (iii*) REPAIRED: a balanced pair remains IN [1/3,2/3] in P
      contradiction follows : YES
      authority             : Op-Form §3.4's recommended repair (mg-e35c F5); this is the predicate mg-3ce3 tests
      cited by mg-345e      : yes — mg-345e §5.1 row (iii)

  -> from L4-AS-STATED the contradiction follows on 1 of 3 branches.
  -> so 'contradicts delta(P) < 1/3 OUTRIGHT' is TRUE ONLY ON BRANCH (i).
     On (ii) it is blocked by mg-3af9 — the same result mg-345e's own §5.1 leans
     on — and on (iii)-as-stated by Op-Form's own PROVEN ledger claim 8.

  WHAT THIS DOES AND DOES NOT TOUCH:
   * It does NOT touch the (A) INDEPENDENT verdict. §2 establishes independence
     by EXHIBITING an L4-free derivation; §3 only argues independence is FORCED.
   * It does NOT reopen §3's conclusion either, because §3's point 2 — the
     direct-prefix route reaches only Delta_1 <= 2/3 against eps_leak ~ 0.20 —
     is independent of point 1 and closes the escape on its own.
   * It DOES mean point 1 is not available as written: an escape that became
     live would not automatically 'dissolve' the question, because L4-as-stated
     firing into (ii) empties nothing.

B4(b) — how much did §3's reachability computation decide?
==============================================================================

out-degree of every node in mg-345e's ARCH_EDGES:
    frozen             -> 1
    pair bias          -> 1
    L1b conclusion     -> 1
    thin prefix        -> 1
    L4 fires           -> 1
    balanced pair      -> 1
    contradiction      -> 0

Every node has out-degree <= 1: the graph is a PATH, not a network.
So `0 paths avoiding X` is true of EVERY interior node, not just of L1b —
which is what a traversal over a path graph must return. Exhibited:

    paths frozen -> L4 fires            : 1
    paths frozen -> L4 fires avoiding `pair bias` : 0
    paths frozen -> L4 fires            : 1
    paths frozen -> L4 fires avoiding `L1b conclusion` : 0
    paths frozen -> L4 fires            : 1
    paths frozen -> L4 fires avoiding `thin prefix` : 0

  -> the traversal has ZERO discriminating power: it returns the same answer for
     `pair bias` and for `thin prefix` as it does for `L1b conclusion`.
     ALL of §3 arm A's content is in the TRANSCRIPTION — i.e. in the claim that
     the architecture has no OTHER route to a thin prefix. mg-345e declares the
     transcription as its Defect 3 and labels the conclusion
     '[PROVEN, on the hand-transcribed step graph]', which is honest; what it
     does not say is that the machine added nothing to it.

  AND THE REAL WORK IS ELSEWHERE AND IS GOOD: mg-345e went looking for the
  missing edge itself (mg-00b9 / mg-2de0, the direct-prefix route) rather than
  trusting the transcription's completeness. That search is the part of §3 that
  carries information, and it is a hand result, not a machine one.
