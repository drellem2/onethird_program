T1b  THE NEXT WORLD-CHANGE, PLANTED IN THE REAL WORKTREE
==============================================================================

  Each plant is its own probe, planted ALONE, so an exit code is
  attributable to one structure.  The restore proof is printed after
  every one of them, and it is MODE-AWARE -- which mg-5040's is not,
  measured rather than asserted in t4_restore.py.

  FOUR COLUMNS AND THEY ARE NOT THE SAME QUESTION.  `names` is whether
  the run prints the planted FILENAME anywhere.  `CAUGHT` is whether a
  SINGLE LINE carries `STILL ASSERTED` and that filename -- the one thing
  a checker prints when it has found a live X4 statement.  `verdict`
  is whether the checker printed its own `TOTAL BAD` line AT ALL: a
  checker that exits 1 without one has not made a finding, it has
  died, and those are the same exit code.  `residue` is the count of
  `declined, NOT STATED` lines, which is the mechanism under audit.

  BASELINE -- nothing planted.  Without it a green run proves nothing
  about the plants, and a red one is not attributable.
