==============================================================================
J3d  THE GENERAL FORM, ON J3
==============================================================================

   1. Every run here is `subprocess.run(["/bin/sh", <name>], ...)`:
      list argv, no `shell=True`, no pipeline, so `returncode` is the
      runner's own.  Structural, not a promise.
   2. `returncode` is read on every path.  A timeout returns None and
      prints `-`, never 0.
   3. Every RED verdict is a CONJUNCTION of exit code, reach of the
      forced marker into the runner's stdout, and no later step having
      run.  Any one of the three alone would pass rows that are wrong:
      code alone passes a runner that died for an unrelated reason;
      reach alone passes the pre-repair text exactly.
   4. `later ran` is measured by STAMPING every later transcript to
      epoch 0 before the run and checking its mtime after -- a file
      that exists is not evidence a step ran, which is mg-6cb9's F2.
   5. The population is DERIVED from J1's parser inside this script,
      not copied into it, so J3 cannot disagree with J1 about which
      runners were fixed.
   6. GREEN is run AFTER RED and restores tracked files between every
      row, so a leaked forced-failure cannot make a GREEN row red.
