[A1.0] THE LEMMA THE WHOLE NEGATIVE RESTS ON, stated plainly:
  (LIB-weak) is an ASYMPTOTIC hypothesis and is therefore INVARIANT
  under modification on a FINITE PREFIX.  (LIB-const) is a POINTWISE
  inequality and a finite prefix can violate it outright.  So for any
  N_0: take any tail that is o(n^2), redefine it below N_0 to exceed
  the bound, and you have a member of (LIB-weak) violating (LIB-const)
  on all of [2, N_0).  §5.3's n^2 / (n^2/log2 n) is ONE instance of
  this; the lemma is what does the work, not the instance.

A4 — DOES THE NEGATIVE REACH THE PROGRAMME'S OBJECT?
==============================================================================
  §5.3 quantifies over the class of o(n^2) FUNCTIONS.  The programme's
  object is the FROZEN POSET class.  These are not the same class, and
  the difference is decidable in one direction:

  IF the frozen class satisfies LIB (E[inv_e] <= C*n) — which mg-c3ca §6
  reports the reachable data as saying — THEN an N_0 DOES exist for the
  frozen class, at C*n <= (eps/6)(n^2-1):
     C =   1:  smallest n with C*n <= (eps/6)(n^2-1)  ->  N_0 = 301
     C =   2:  smallest n with C*n <= (eps/6)(n^2-1)  ->  N_0 = 601
     C =  10:  smallest n with C*n <= (eps/6)(n^2-1)  ->  N_0 = 3001

  This does NOT contradict §5.3.  It is the class/member distinction:
  a threshold exists for that FAMILY, it is just not a function of the
  o(n^2) hypothesis.  It is exactly what row 8's 'What it does not
  claim' paragraph says.  Recorded here because the SHORT sites say
  'find N_0 is closed, not open' and this is the reading that must not
  be welded to them.
