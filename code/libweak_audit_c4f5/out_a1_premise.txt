A3. THE IMPLICATION ITSELF, made quantitative rather than asserted
------------------------------------------------------------------------------
(LIB-weak) says E[inv_e]/n^2 -> 0.  Through the master bound that is
1-lambda_std <= 6(E[inv_e]/n^2)(n^2/(n^2-1)) -> 0.  The map is monotone and
explicit, so the implication is arithmetic.  Tabulated so the constant is visible:
  if E[inv_e]/n^2 <=           then 1-lambda_std <= (n large)
  0.1                          0.6                         
  0.01                         0.06                        
  0.00333333                   0.02                        
  0.001                        0.006                       
  0.0001                       0.0006                      

So (LIB-weak) => lambda_std -> 1 : CONFIRMED, and it is ONE division.
The content is entirely in the master bound, which mg-c3ca did not re-derive.

------------------------------------------------------------------------------
B2. AND WHAT THE MASTER BOUND LOOKS LIKE AT THE MAJORITY ORDER e
------------------------------------------------------------------------------
For a frozen poset e exists and is a linear extension, so the right reading of
the bound is 1-lambda_std(e) <= 6E[inv_e]/(n^2-1).  E_maj = E[inv_e] is the
MINIMUM of E[inv_L] over reference orders -- but lambda_std(e) is not the
minimum of lambda_std(L), so the two minima are not taken together.  Checked:
  n=5, posets with a majority linear extension:
  lambda_std(e) is the MAXIMUM over reference orders : 97
  lambda_std(e) is strictly BELOW the maximum        : 44

  (If e were not the maximiser, `lambda_std -> 1` at e would be a WEAKER
   conclusion than at the best reference order -- worth knowing which way it
   points, since the architecture wants lambda_std LARGE.)
