B. Sec.1 -- BOTH DIRECTIONS OF THE IFF, as finite-n inequalities
------------------------------------------------------------------------------
The proof is two Markov steps.  At finite n they are these two inequalities,
and if either failed the iff would be wrong:
   (=>)  #{x : m_x >= alpha n}  <=  2 E[inv] / (alpha n)
   (<=)  sum_x m_x  <=  #{x : m_x >= alpha n} * n  +  alpha n * n
  406632 (poset, alpha) instances;  (=>) violations 0 ;  (<=) violations 0
  P4 predicted 0 and 0.

C. Sec.1 -- THE QUANTIFIER IN THE Sec.3 TABLE (P4's predicted defect)
------------------------------------------------------------------------------
Sec.1 states the iff correctly:
    (LIB-weak) <=> for every alpha>0, #{x : m_x >= alpha n} = o(n).
Sec.3's table states its NEGATION as:
    "#{x : m_x >= alpha n} = Omega(n) for some alpha > 0"
The correct negation of `= o(n)` is `is NOT o(n)`, i.e. limsup count/n > 0,
which permits a SUBSEQUENCE.  Omega(n) as normally read demands it at EVERY n.
This is strictly stronger than the negation, so the table's row is a slightly
stronger claim than the section it cites.  Consequence: NONE for the verdict --
a (LIB-weak) violator along a subsequence is still a violator.
  VERDICT: substance CONFIRMED, one quantifier written too strongly. NO CONSEQUENCE.

D. Sec.4 Prop 4.1 -- the entropy price, instantiated
------------------------------------------------------------------------------
Claim: E[inv_e] <= eps n^2  ==>  e(P) <= 2 * C(2 eps n^2 + n, n).
Instantiated at eps = E[inv]/n^2, i.e. e(P) <= 2 * C(floor(2E[inv]) + n, n).
NOTE the reference order: Prop 4.1's coding counts inversions of sigma against e
OVER ALL PAIRS, and inv_e counts only INCOMPARABLE pairs.  They coincide only
because e is a linear extension (P6).  Tested with L = the natural labelling,
which IS a linear extension, so the identification is legitimate here.
