C2. THE CLASS CHAIN, FALSIFIED BY CONSTRUCTION
------------------------------------------------------------------------------
mg-c3ca Sec.2.3 bullet 1 (quoting mg-88bd Sec.6.2):
    `(LIB) O(n) c (LIB-weak) o(n^2) c (LIB-const) <= c n^2`
An inclusion of classes IS an implication.  Bullet 2 then says `neither implies
the other outright`.  Both cannot be read literally.  Which is right:

Construction: f(n) = n^2 / log2(n)  for n >= 2, f(n) = 10^6 for n < 2.
f is o(n^2).  Is f <= c n^2 at EVERY n for the architecture's c = eps_spec/6?
  c = eps_spec/6 = 0.00333333   (at the repaired eps_spec = 2e-2)
  f(n) <= c n^2  <=>  log2(n) >= 1/c = 300  <=>  n >= 2^300 ~ 10^90
  So f is o(n^2) and VIOLATES (LIB-const) at EVERY n below about 10^90.
  (At the SUPERSEDED eps_spec = 2e-4 the same construction runs to 10^9031.)

  AND THE THRESHOLD IS UNBOUNDED, not merely large: for ANY N0 whatsoever,
  g(n) := n^2 for n < N0 and n^2/log2(n) for n >= N0 is o(n^2) and violates
  (LIB-const) below N0.  So `N0 unspecified` is not a technicality about an
  unknown constant -- NO N0 EXISTS that works for all of (LIB-weak).

  VERDICT C2: as a statement about GROWTH-RATE CLASSES with (LIB-const) read as
  O(n^2), the chain is correct.  As a statement about the OBJECTS satisfying the
  three conditions at the architecture's own constant, `(LIB-weak) c (LIB-const)`
  IS FALSE, and the failure interval is unbounded over the class.
  Bullet 2 is right and bullet 1 needs the rider AT ITS OWN SITE.  This is the
  same defect mg-325c repaired in STATE.md at four sites, surviving in the doc.

  AND THE TWO GAPS ARE NOT COMPETITORS.  C1's factor (50) and C2's quantifier
  are different objects:
    C1 = (what freezing gives free) vs (what the architecture needs) : a CONSTANT
    C2 = (LIB-weak) vs (LIB-const)                                  : a QUANTIFIER
  A relay that says `the residual is a constant (~50) RATHER THAN a quantifier`
  has set two true statements about different pairs against each other.
