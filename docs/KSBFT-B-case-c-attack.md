## 1. Part 1 — pricing the displacement-M route

### 1.1 What the route is

Section 4 of the paper is a **proof by contradiction confined to a window**. It assumes δ(P) ≤ C_BFT + η_D. Lemma 3.2 then says every BFT triple (x, y, z) is a bridged 2+1:

- y is incomparable only to x and z;
- X = L ⊔ {x,y,z} ⊔ U, with L ≺ y ≺ U, L ≺ z, x ≺ U, and x ⋖ z.

Lemma 4.1 picks the consecutive triple (v_m, v_{m+1}, v_{m+2}) at which |d| = M. Lemma 4.2 converts M into balance, and (4.11) bounds M from below.

### 1.2 Re-derivation of the height identities

Assume Lemma 3.2's conclusions and x = v_m, y = v_{m+1}, z = v_{m+2}. Then |L| = m − 1: every w ∈ L has w ≺ y, so h(w) < h(y) and w precedes x in h-order; symmetrically for U. Let f be uniform.

- Before x there can only be elements of L and y, because x ≺ z and x ≺ U. So f(x) − 1 = (m − 1) − #{w ∈ L after x} + 1[y before x], and taking expectations **h(x) = m + p − α**.
- Before z sit all of L (L ≺ z), x, y unless z precedes y, and the U-elements before z. So **h(z) = m + 2 + β − p′**.
- The BFT condition h(z) − h(x) ≤ 2 then reads **α + β ≤ p + p′** (4.6).

For the extension count, write e(P) = e(L′)e(U′)Z with Z = 1 + r + s. A pair of extensions of P[L′] and P[U′] extends in 1 + 1[x last] + 1[z first] ways (paper (4.2); checked). Summing m − g_{L′}(x) with those weights, and noting the term vanishes when x is last, gives α = (1+s)t/Z. The same argument gives β = (1+r)u/Z. Since x is not last with probability 1 − r and then has at least one element after it, t ≥ 1 − r; likewise u ≥ 1 − s. Substituting into (4.6) gives (1+s)(1−r) + (1+r)(1−s) ≤ r + s, i.e. **g := r + s + 2rs − 2 ≥ 0** (4.7).

### 1.3 Prop A (PROVEN-mod-paper): under Lemma 3.2's structure, M ≤ max(p, p′) = max(δ(P;x,y), δ(P;y,z)) ≤ 1/2

*Proof.* d_m = p − α and d_{m+2} = β − p′. Since α, β ≥ 0 and α + β ≤ p + p′:

- d_m ≤ p;
- −d_m = α − p ≤ p′;
- d_{m+2} ≤ (p + p′ − α) − p′ ≤ p;
- −d_{m+2} ≤ p′.

By Lemma 4.1, M = max(|d_m|, |d_{m+2}|) ≤ max(p, p′). Finally p, p′ ≤ 1/2 (Corollary 2.2), so max(p, p′) = max(δ(P;x,y), δ(P;y,z)). ∎

**Consequences.**
(a) In the paper's regime δ ≤ C_BFT + η_D we get M ≤ 0.2764. So Lemma 4.2's M²/441 ≤ 1.7·10⁻⁴ there, and the needed M ≈ 5.01 is 18× above what the lemma can ever see.
(b) Prop A is a conversion in its own right: **balance ≥ M**. Along this route, 1/3 follows whenever M ≥ 1/3 at a structured triple.

`local_model.py` check C2 tests |d| ≤ a on 152 623 feasible points of the relaxation and finds 0 violations. Check C5 shows the bound is attained (g(μ) ≈ μ for μ ≥ 0.35), so a weaker claim such as |d| ≤ 0.9a *would* fire. That is the positive control.

### 1.4 The exact price with the paper's inputs: M ≥ 1/3 (EMPIRICAL, sharp)

The relaxation Lemma 4.2's proof actually uses is: r, s ∈ [0,1], t ≥ 1−r, u ≥ 1−s, (1+s)t + (1+r)u ≤ r + s. Over it, define g(μ) = min{ a : max|d| ≥ μ }. From `out_local_model.txt` C5 and `out_threshold.txt`:

## 2. Part 2(i) — a D-uniform-shaped witness and a linear conversion

### 2.1 Prop B (PROVEN): if G(P) is connected, n ≥ 2 and π(P) ≤ D, then d₁ = h(v₁) − 1 ≥ 1/(D+1). This is tight.

*Proof.*

1. **v₁ is minimal.** If w ≺ v₁ then f(w) < f(v₁) always, so h(w) < h(v₁), contradicting the choice of v₁.
2. **Write a = v₁.** Since G(P) is connected and n ≥ 2, a has an incomparable element.
3. **The two sets.** Let E₁ = {extensions with f(a) = 1} and E₂ = {extensions with f(a) = 2}.
4. **The map φ: E₁ → E₂.** For g ∈ E₁, let c be the first element (in g) incomparable to a, at position t ≥ 2. Every element u at positions 2..t−1 is comparable to a and after it, so u ≻ a. None of them is below c, since u ≺ c would give a ≺ c. None is above c, since u precedes c. So each u ∥ c. Hence nothing precedes c in P among positions 1..t−1, and moving c to the front gives a linear extension φ(g) with c first and a second.
5. **φ is at most D-to-1.** Given φ(g), c is its first element, and g is recovered from φ(g) and t. The elements a, u₂, …, u_{t−1} are all incomparable to c, so t − 1 ≤ π(c) ≤ D. Thus t ∈ {2, …, D+1}.
6. **Conclusion.** |E₁| ≤ D·|E₂| ≤ D·(e(P) − |E₁|). So P[f(a) = 1] ≤ D/(D+1), and d₁ = E[f(a)] − 1 ≥ P[f(a) ≥ 2] ≥ 1/(D+1). ∎

**Tightness.** Take a D-chain c₁ ≺ … ≺ c_D and one element w incomparable to all of it. Then v₁ = c₁ and d₁ = P[w first] = 1/(D+1).

**Live check.** `census` prints min d₁·(π+1) per row. In `out_census_all.txt` it is ≥ 1 in every row for n ≤ 8, and exactly 1.000000 in the rows (n, π) = (3,2), (4,3), (5,4), (6,5), (7,6), (8,7). Those are the chain-plus-point posets.

**Why the paper's bound is (D+1)^(−2(D+1)).** Lemma 3.1 bounds *any* S-dependent event by comparing e(Q) with e(P). It pays (D+1) for every element of T = S ∪ (all elements incomparable to S), and |T| ≤ |S|(D+1) = 2(D+1). The bound is uniform over all events and exponential by construction. The single-pair event {v_j before v₁} in (4.11) only needs the injection above.

**Is exponential ever necessary?** For *generic* 2-element events, yes. Two parallel k-chains have P[top of A before bottom of B] = 1/C(2k,k) ≈ 4^(−k) with range k. At n = 8, `out_census_all.txt` records min P[u<v] = 0.014286 = 1/70 at π = 4. So Lemma 3.1's shape is right for arbitrary events, and the gain in Prop B comes from the event being about the *minimum-height* element.

### 2.2 Prop C (PROVEN-mod-paper): linear conversion. Under Lemma 3.2's structure, at Lemma 4.1's triple, a := max(δ(P;x,y), δ(P;y,z)) ≥ C_BFT + M/24.5.

*Proof.* Write ρ = (√5−1)/2, so C_BFT = ρ/√5 and 1 + 2ρ = √5. Let r = ρ + X and s = ρ + Y, with |X|, |Y| ≤ ρ, W = |X| + |Y|, Z = 1 + r + s ≤ 3, and ε = a − C_BFT.

1. **ε dominates W.** Since a = max(r, s)/Z, a direct expansion gives r/Z − C_BFT = ((1+ρ)X − ρY)/(Z√5), and symmetrically for s. So εZ√5 ≥ max(A, B) with A = (1+ρ)X − ρY and B = (1+ρ)Y − ρX. Here A + B = X + Y and A − B = √5(X − Y).
2. **X + Y ≥ 0.** Substituting into (4.7), g = √5(X+Y) + 2XY ≥ 0. If X + Y < 0 and XY ≤ 0, then g < 0. If X + Y < 0 and XY > 0, both are negative, and 2|X||Y| ≤ 2ρ|Y| < √5(|X|+|Y|), so again g < 0. Hence X + Y ≥ 0.
3. **Bound on W.** From steps 1 and 2, εZ√5 ≥ (A+B)/2 + |A−B|/2 ≥ max(X, Y) ≥ W/2. So **W ≤ 2√5·Zε**.
4. **Bounds on the displacements.** Let α* = α − (1+s)(1−r)/Z ≥ 0 and β* = β − (1+r)(1−s)/Z ≥ 0. From (4.6), α* + β* ≤ g/Z. Then d_m = F/Z − α* and d_{m+2} = G/Z + β*, where:
   - F = r − (1+s)(1−r) = (2+ρ)X − (1−ρ)Y + XY;
   - G = (1+r)(1−s) − s = (1−ρ)X − (2+ρ)Y − XY.
   Both satisfy |F|, |G| ≤ (2+ρ)W. Also g ≤ √5W + 2|X||Y| ≤ (√5 + ρ)W. Hence |d| ≤ (2 + 2ρ + √5)W/Z = (1 + 2√5)W/Z ≤ (1 + 2√5)·2√5·ε = (20 + 2√5)ε < 24.5ε. ∎

**Checks.** `local_model.py` C4 gives the empirical sup of |d|/ε over the relaxation as **5.85**, so 24.5 is loose by about 4×. C3 confirms the paper's own inequality |d| ≤ 21√ε with 0 violations. The paper's √ε came from bounding (r − s)² ≤ 50ε. In fact r − s is controlled *linearly*, because a is the maximum of two linear forms whose cone contains the feasible directions (step 2).

### 2.3 Theorem 1.3′ (PROVEN-mod-paper): if π(P) ≤ D, D ≥ 2 and P is finite non-chain, then δ(P) > C_BFT + (D+1)^(−3(D+1))/12

*Proof.*

1. **Setup.** Take a connected component, as the paper does. Let θ = q₃/12 with q₃ = (D+1)^(−3(D+1)), and suppose δ(P) ≤ C_BFT + θ.
2. **Lemma 3.2 applies.** Lemma 3.2 uses its hypothesis only through two facts: δ ≤ 0.2764, true because θ ≤ 3⁻⁹/12, and R ≤ (5+3√5)θ < q₃, true because 5+3√5 < 11.71 < 12. So its conclusions hold for every BFT triple.
3. **The contradiction.** Take Lemma 4.1's triple. Prop C and Prop B give δ(P) ≥ a ≥ C_BFT + M/24.5 ≥ C_BFT + d₁/24.5 ≥ C_BFT + 1/(24.5(D+1)). That is > C_BFT + θ, contradicting step 1. ∎

**Comparison.** η_D = (D+1)^(−4(D+1))/4096 becomes η′_D = (D+1)^(−3(D+1))/12. At D = 6 that is about 10^(−18.8) instead of 10^(−27.3). The window θ is now the whole loss. The witness term 1/(24.5(D+1)) is polynomial and slack.

For D = 2 alone, Prop A suffices without Prop C: M ≥ 1/3 > 0.2764. That rules out the regime, but it only reproduces what the paper already covers at D = 2.

## 4. Part 2(ii) — boundary witnesses

### 4.1 Prop D (PROVEN-mod-paper): in the near-C_BFT regime, BFT triples stay away from both ends

Assume the §2.3 setting (δ ≤ C_BFT + θ, so Lemma 3.2's structure holds for every BFT triple), and fix any BFT triple with L′, U′.

1. **r is a ratio of counts.** x is maximal in L′: w ≻ x with w ∈ L would give x ≺ w ≺ y, contradicting x ∥ y. So r = P[x last in P[L′]] = e(L)/e(L′) is a ratio of integers.
2. **Golden ratio lemma (PROVEN).** For all integers p and q ≥ 1, |ρ − p/q| ≥ 1/((1+√5)q²). Proof: with ρ′ = (−1−√5)/2, the product (qρ − p)(qρ′ − p) = p² + pq − q² is a nonzero integer. Also |qρ′ − p| ≤ |qρ − p| + √5q. So δ₀ = |qρ − p| satisfies δ₀(δ₀ + √5q) ≥ 1, which gives δ₀ ≥ 1/((1+√5)q) whether δ₀ ≤ 1 or δ₀ > 1.
3. **Linking to ε.** By Prop C's step 3, |r − ρ| ≤ W ≤ 6√5ε with ε ≤ θ. Combining with step 2 gives **e(P[L′]) ≥ (6√5(1+√5)ε)^(−1/2) ≥ (43.5θ)^(−1/2)**, and the same for e(P[U′]).
4. **Converting counts to depth.** Every subposet of range ≤ D has an antichain of minimal elements of size ≤ D+1 at each step, so e(Q) ≤ (D+1)^|Q|. Hence every BFT triple has |L′|, |U′| ≥ log(1/(43.5θ)) / (2 log(D+1)).

In particular, (v₁, v₂, v₃) is never a BFT triple in the regime: it would have e(L′) = 1 and r = 1, which gives a ≥ 1/(2+s) ≥ 1/3. This is exactly where F_m's endpoint pairs (≈ 0.382) live.

**What would close case (c) this way (CONJECTURED shape).** One would need a lemma saying every finite connected poset of range ≤ D has a BFT triple (or a Case A/B/C triple) within the first or last K elements of h-order, with K growing slower than log(1/θ)/log(D+1). Combined with Prop D, that contradicts the regime. It still lives inside Lemma 3.2's window, because Prop D consumes the structure, so it improves the *witness* side and not the window. I did not find such a lemma. The obstacle is that the non-BFT condition d_{k+2} > d_k on a long prefix does not contradict |d| ≤ 24.5θ by itself.

### 4.2 Direct boundary balance (EMPIRICAL)

Let B_K be the best balance over incomparable pairs lying inside the first K or inside the last K elements of h-order.

- **Exhaustive, n ≤ 8** (`out_census_all.txt`): B₄ ≥ 1/3 in every row. It equals exactly 1/3 at π = 4, 5, 7, and B₄ < δ in some rows. B₃ reaches 0.2807 (n=7, π=4) and 0.2857 (n=8, π=5). B₂ can be 0.
- **Annealing, n = 10, 14, 18 and D = 3..9** (`out_search_summary.txt`; earlier ad-hoc runs at n = 16, 20 agreed):
  - B₄ min is exactly 1/3 for D ≤ 4, but **0.309** at D = 5, 6 and **0** at D ≥ 8. For B₄ = 0, the first and last four elements are chains.
  - B₅ min ≥ 1/3 for D ≤ 6 (0.3337 at n=14, D=6), but 0.3094 at n=18, D=7.
  - B₆ min ≥ 0.3333 for all D ≤ 9 searched.
- These are upper bounds on true minima, from a search started at F_m. They are **weak evidence**: seeds disagree by up to 0.04.

CONJECTURED: for each D there is K(D) with B_{K(D)} ≥ 1/3 for all finite connected posets of range ≤ D. Observed K = 4, 5, 6 for D ≤ 4, 6, 9, consistent with K(D) ≈ D/2 + 2. This is equivalent to the conjecture itself for range ≤ D. Its interest is that it is a *local* statement.

## 5. Part 2(iii) — reduction to a bounded window (not achieved; CONJECTURED shape)

With π ≤ D, elements more than about D apart in h-order are comparable, so P is a banded object. A linear extension is a walk through order ideals whose "frontier" has at most D+1 minimal elements, which is a transfer-matrix structure with finitely many local types for fixed D.

Heuristic reduction: take a sequence of counterexamples P_n with range ≤ D and δ(P_n) < 1/3. Those must have n > 14 (Gup26). Extract the local limit at the left end, which is a one-sided infinite poset of range ≤ D, and show that its left-end pairs have limiting balances. For F this is what gives 0.382.

This turns case (c) at fixed D into a statement about one-sided infinite range-D posets **only if** boundary probabilities converge uniformly in the far end, i.e. a D-dependent decay-of-correlations bound. In F_m the correction is exponential (|d| ∝ φ^(−2·distance), `out_fib.txt`), but I have no uniform-in-class decay estimate. Such a compactness argument would give K(D) and a finite check per D, but no explicit K(D) unless the decay rate is effective. **What grows with D** is the number of frontier types, up to about 2^(D+1) antichain patterns times their comparabilities, and the mixing length, for which I have no bound.

I did not read Brightwell–Wright 1992 or Peczarski 2008, so I cannot say whether their D ≤ 5 and D ≤ 6 proofs are of this finite-check form.
