### 1.1 The operation, and the theorem

> **Definition.** `x` is a **cut element** of `P` if it is comparable to every other element. `Q` is a **cut
> extension** of `P` if `Q` is `P` with one new element adjoined comparable to everything, in a position
> leaving `e(Q) = e(P)`. The **core** of `P` is `P` with cut elements deleted repeatedly while `e` is
> preserved.

> **Theorem (one line).** If `Q` is a cut extension of `P` then `δ(Q) = δ(P)`.
>
> *Proof.* `e(Q) = e(P)` says every linear extension of `P` already places the ideal below the new element `z`
> as a prefix, so the linear extensions of `Q` are exactly those of `P` with `z` inserted at one fixed
> position. `z` is comparable to everything, so `Inc(Q) = Inc(P)` and `p_Q(x,y) = p_P(x,y)` for every
> incomparable pair. Hence `δ(Q) = δ(P)`. ∎

`qmass` is not proved invariant here; it is **measured**, on every cut extension of every poset in the §4
population at `n = 5` and `n = 6`:

```

  (delta, qmass) inherited             : 257
  inheritance failures                 : 0
```

### 1.3 What is and is not wrong in the repair's §3.3

The repair states its post-hoc position at length and states it three ways, and the *pre-specification itself

The separation is **real**, and I made a deliberate attempt to break it by going where the repair could not.
Posets with `e(P) ≤ 9` are closed under deleting a maximal element (`e(P − x) ≤ e(P)` for `x` maximal), so

The separation holds at every size. The `n = 9` group contains the only genuinely new poset in the whole range

The refuting conjunction is realisable, so the hypothesis is falsifiable as a statement about posets:

```

  5 |                         3 |              23.08% |                     0
```

24 of the 36 posets with `qmass = 1` at `n = 8` are **not** extremal. What is claimed is that this never
happens *inside an `e`-group that contains an extremal poset*, and that is a genuine restriction, not a
definitional one. It has had **six** independent chances to fail and has not taken any of them.

### 1.5 One structural note the repair does not make

Within an `e = 9` group `δ` can only be `1/3` or `4/9`: every incomparable pair splits `k : 9−k`, so
`min(p,1−p) ∈ {1/9, 2/9, 3/9, 4/9}`, and the first two are excluded because they would be counterexamples to
the conjecture. The response variable is therefore **binary by construction** in every group the repair
reports, and the "distinct `δ`" column reading `2` is forced rather than observed. This does not invalidate
anything; it is the kind of fact that belongs next to a `2 × 3` contingency table being reported as a
separation.
